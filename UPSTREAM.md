# Upstream Provenance

MIRAI is a transparent derivative of the Apache-2.0-licensed source repository at `https://github.com/chenyiqun/JADE`, pinned at commit `5dae72423fbbd30a22b49b494398818e7699d195`.

The public MIRAI history begins from a sanitized source snapshot rather than mirroring upstream Git objects. This is necessary because the upstream history contained a credential in example launcher files. The snapshot preserves the upstream license and NOTICE attribution while preventing that credential from entering MIRAI history.

The original Apache-2.0 `LICENSE` is retained unchanged. The upstream notice is retained in `Notice.txt` and `NOTICE`; additional provenance appears in `THIRD_PARTY_NOTICES.md`.

MIRAI does not claim that reused third-party code was authored independently from scratch.
