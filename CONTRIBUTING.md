# Contributing to MIRAI

Thank you for improving MIRAI. This repository combines MIRAI-specific Planner-Executor integration with retained Apache-2.0-licensed framework code. Contributions should preserve scientific terminology, provenance, and operational safety.

## Before Opening a Pull Request

1. Describe the problem, expected behavior, and validation performed.
2. Do not commit credentials, private endpoints, datasets, checkpoints, `.env` files, host lists, or generated bytecode.
3. Preserve copyright and license headers in third-party-derived files. Add a prominent modification notice when changing a retained source or configuration file.
4. Keep `verl` names and contributor identities where they denote the retained framework or third-party provenance; use MIRAI terminology for MIRAI-owned documentation, prompts, scripts, logs, and examples.

## Local Checks

Run the focused checks that apply to your change:

```bash
python -m compileall -q qa_manager verl
python -m pytest tests/mirai
bash -n check_cluster_env.sh
bash -n examples/ppo_trainer/run_qwen2.5.sh
bash -n examples/ppo_trainer/run_qwen2.5_test.sh
```

For the safe launcher configuration check:

```bash
MIRAI_PYTHON_BIN=echo MIRAI_TRAIN_DATA=/tmp/train.parquet MIRAI_VAL_DATA=/tmp/val.parquet \
  bash examples/ppo_trainer/run_qwen2.5.sh
```

Full distributed training and benchmark evaluation require separately provisioned Linux/CUDA infrastructure, data, and retrieval services. Do not report them as run unless they were actually executed.

## Documentation and Scientific Changes

Use the canonical identity:

```text
MIRAI
Multi-agent Integrated Retrieval, Adaptation, and Inference
```

Changes to method descriptions, benchmark numbers, equations, figures, tables, or experiment claims must preserve the retained-source-study scope. See `README.md`, `UPSTREAM.md`, and `THIRD_PARTY_NOTICES.md` before altering scientific or provenance language.

## Reporting Security Issues

Use GitHub private security reporting for potential vulnerabilities. Never open a public issue containing a live credential or private infrastructure detail.
